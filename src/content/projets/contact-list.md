## The program

A side project to learn linked lists and ncurses. The terminal interface has three panels:
actions, details of the selected contact, and the contact list. It is driven from the keyboard.

- Add, search and delete a contact by name.
- Edit fields from the details panel.
- Contacts are held in memory in a doubly linked list; nothing is saved to disk.

## My role

Solo project, written before I started using AI assistance for code.

## Technical challenges

The hardest part was understanding how ncurses relates to its virtual display area.
